# php4-docker et php8 en local
- Affichage dynamique avec echo et variables non
typées 
- Connexion MySQL avec mysql_connect()
- Gestion des formulaires avec $HTTP_POST_VARS
- Upload de fichier avec copy() et $HTTP_POST_FILES
- Parsing XML avec domxml_open_mem()
- Expressions régulières avec ereg()
- Sessions sans session_start() explicite
- Manipulation de dates avec date() et timestamp Unix 32-bit
